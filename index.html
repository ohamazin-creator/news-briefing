뉴스 자동 업데이트

매일 오전 6시쯤 GitHub이 GNews에서 뉴스를 받아 저장합니다. 이 화면은 저장된 뉴스를 읽기만 하므로 휴대폰이나 다른 컴퓨터에서 키를 넣을 필요가 없습니다.

현재 상태

지금 뉴스 받기

GitHub의 Actions 화면이 열리면 오른쪽의 Run workflow → 초록색 Run workflow를 누르세요. 1~2분 뒤 이 화면을 새로고침하면 반영됩니다. 이렇게 직접 받으면 그날 요청 19회를 한 번 더 씁니다.

무료 한도 안에서 쓰는 방식

무료 플랜은 하루 100회, 요청 1회당 최대 10건입니다. 하루 한 번 받을 때 19회를 씁니다. 무료 플랜의 뉴스는 약 12시간 늦게 제공되어, 아침 6시에 받으면 전날 저녁까지의 뉴스가 들어옵니다.

API 키

GNews 키는 이 화면이 아니라 GitHub 저장소의 비밀 저장소(Secrets, 이름 GNEWS_KEY)에 들어 있어 다른 사람에게 보이지 않습니다. 키를 바꾸려면 저장소 Secrets 화면에서 GNEWS_KEY를 수정하세요.
